# Life After Hard Times

Hub page for Jane Ratliff's speaking brand. Introduces both talks and routes
visitors to each:

- **Don't Press Reply** — fraud-prevention talk for senior living and 55+ communities
- **Why Nobody Called** — domestic abuse awareness talk for DV nonprofits, shelters, and campus programs

Static site — a single `index.html` with inline CSS, no build step, no
framework. Deploys on Netlify. Intended to live at the root of
`lifeafterhardtimes.com`.
